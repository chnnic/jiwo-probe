# LuminaPlus visual reference

Jiwo's independent LuminaPlus implementation uses Jiwo components and data APIs.
The card layout, segmented meters and color palette are inspired by
[Komari-Theme-LuminaPlus](https://github.com/shanyang242/Komari-Theme-LuminaPlus)
(reference revision `a52305e1c26c68bd741a079c4ff50f7b3a5a016e`).
That project builds on [Komari Theme Lumina](https://github.com/stqfdyr/komari-theme-Lumina).
No third-party site data, private configuration, logos or credentials are bundled.

The reference project's MIT notice is retained below for the adapted visual design.
